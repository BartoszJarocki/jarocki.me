Residual stream, 3D review prototype

Tokens run left to right. Three number positions run down each plane. Depth follows one block's input and its two additions. These are made-up numbers, shared with the SVG demo.


Attention reads leveled copies and adds to the input. The small network reads leveled copies and adds again. Filled squares are positive. Hollow squares are negative. Square size shows distance from zero.
